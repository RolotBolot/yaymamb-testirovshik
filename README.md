## Пет-проект: тестирование Restful-booker API

Самостоятельное ручное тестирование публичного API бронирования
([restful-booker.herokuapp.com](https://restful-booker.herokuapp.com)) в Postman.

**Что сделано:**
- Протестированы все эндпоинты: `GET /ping`, `GET /booking`, `GET /booking/{id}`, `POST /auth`, `POST /booking`, `PUT /booking/{id}`, `DELETE /booking/{id}`
- Проверены позитивные сценарии и негативные: отсутствующие и пустые обязательные поля, отрицательные значения, некорректный диапазон дат, запросы без авторизации, неверные учётные данные
- Результат каждой операции проверялся не только по статус-коду, но и по фактическому состоянию ресурса

**Найдено 7 дефектов**, в том числе:
1. `500 Internal Server Error` при отсутствии обязательного поля в теле запроса
2. Авторизация с неверным паролем возвращает `200 OK` вместо `401 Unauthorized`
3. Отсутствие валидации: принимаются отрицательная стоимость и дата выезда раньше даты заезда
4. Несогласованность кодов ответа: создание возвращает `200`, удаление — `201`
